> **팀 적용 주제:** K-Means를 이용한 고객 구매행동 군집분석  
> **작성 기준:** 2026년 11월 2일

## 1. 인공지능·머신러닝·딥러닝의 관계

### 1.1 인공지능(Artificial Intelligence, AI)

인간의 지능적 활동으로 여겨지는 추론, 탐색, 학습, 인식, 계획 등을 컴퓨터 시스템으로 구현하려는 분야이다. **모든 인공지능이 반드시 데이터를 통해 학습하는 것은 아니다.** 규칙 기반 시스템이나 탐색 알고리즘도 인공지능에 포함될 수 있다.

### 1.2 머신러닝(Machine Learning, ML)

사람이 모든 판단 규칙을 직접 작성하지 않고 **데이터로부터 패턴이나 규칙을 학습**하는 방법이다.

- 입력 특성(feature): 예측이나 분석에 이용하는 데이터의 속성. 예: 나이, 구매금액, 과거 구매횟수.
- 모델(model): 입력으로부터 예측 결과 또는 데이터 구조를 만들어 내는 수학적·계산적 체계.
- 학습(training): 주어진 목적에 맞도록 모델의 파라미터를 추정하는 과정.
- 일반화(generalization): 학습에 사용하지 않은 데이터에서도 적절한 결과를 내는 능력.

### 1.3 딥러닝(Deep Learning, DL)

여러 층의 신경망을 이용하여 데이터에서 표현을 학습하는 머신러닝의 하위 분야이다. 이미지·음성·언어 등 복잡한 비정형 데이터에 강점을 보일 수 있지만, **딥러닝이 언제나 전통적인 머신러닝보다 우수한 것은 아니다.** 표 형태의 정형 데이터에서는 단순한 통계 모델이나 트리 기반 모델이 더 적합할 수 있다.

관계는 **인공지능 ⊃ 머신러닝 ⊃ 딥러닝**이다.

| 구분 | 핵심 특징 | 예시 |
| --- | --- | --- |
| 규칙 기반 AI | 사람이 명시한 규칙에 따라 판단 | 조건문 기반 의사결정 |
| 전통적 머신러닝 | 데이터에서 패턴을 학습 | 선형회귀, 로지스틱 회귀, 의사결정나무, K-Means |
| 딥러닝 | 다층 신경망으로 표현을 학습 | MLP, CNN, Transformer |

## 2. 머신러닝의 학습 방식

### 2.1 지도학습(Supervised Learning)

정답 또는 목표값인 **레이블(label, target)** 이 있는 데이터를 학습한다.

- **회귀(Regression):** 연속적인 수치 예측. 예: 고객의 다음 구매금액 예측.
- **분류(Classification):** 범주 또는 클래스 예측. 예: 고객의 구독 여부 예측.

일반적으로 입력을 $X$, 목표값을 $y$라고 나타내며, 모델은 $f(X)$가 $y$와 가깝도록 학습한다.

### 2.2 비지도학습(Unsupervised Learning)

미리 주어진 정답 레이블 없이 데이터의 구조와 패턴을 찾는다.

- **군집화(Clustering):** 비슷한 데이터끼리 묶는다. 예: 구매행동이 유사한 고객 그룹 탐색.
- **차원 축소(Dimensionality Reduction):** 정보의 주요 구조를 보존하면서 변수 수를 줄인다. 예: PCA.
- **이상치 탐지(Anomaly Detection):** 다른 관측치와 상당히 다른 데이터 탐색. 다만 이상치 탐지는 지도·비지도·준지도 등 다양한 방식으로 수행된다.

**주의:** K-Means가 고객을 0·1·2번 군집으로 나눴다고 해서 이를 고객의 실제 정답 범주라고 해석할 수는 없다. 군집 번호는 알고리즘이 부여한 임의의 식별자다.

### 2.3 그 밖의 학습 방식

- **자기지도학습(Self-supervised Learning):** 데이터 자체로부터 학습 목표를 생성한다.
- **강화학습(Reinforcement Learning):** 에이전트가 환경과 상호작용하며 보상을 최대화하는 정책을 학습한다.

이 둘은 5주차의 주된 실습 주제는 아니지만 머신러닝 전반을 이해할 때 구분할 필요가 있다.

## 3. 베이스라인(Baseline) 모델

### 3.1 정의

**베이스라인은 이후 모델이나 분석 방법의 가치를 판단하기 위한 기준선**이다. 반드시 특정 알고리즘을 가리키는 말은 아니다. 비교 기준은 문제의 형태에 맞게 설계해야 한다.

베이스라인을 먼저 만드는 이유는 다음과 같다.

1. 복잡한 방법이 실제로 개선을 가져오는지 확인한다.
2. 데이터와 문제 정의가 올바른지 점검한다.
3. 개발 시간과 계산 비용의 증가를 정당화할 근거를 마련한다.
4. 동일한 조건에서 재현 가능한 실험을 수행한다.

### 3.2 지도학습에서의 베이스라인

| 문제 | 단순 기준선 예시 | 이후 비교 모델 예시 |
| --- | --- | --- |
| 분류 | 가장 빈번한 클래스만 예측하는 DummyClassifier | 로지스틱 회귀, 결정트리, 랜덤 포레스트 |
| 회귀 | 훈련 데이터 목표값의 평균을 예측하는 DummyRegressor | 선형회귀, 랜덤 포레스트 회귀 |

예를 들어 1,000명 중 900명이 미구독자라면, 모든 고객을 미구독자로 예측하는 모델의 **정확도는 90%**다. 따라서 새로운 모델의 정확도가 91%라고 해도 이를 곧바로 좋은 모델이라고 평가할 수 없다. 클래스 불균형이 있다면 정밀도·재현율·F1 등도 함께 살펴봐야 한다.

### 3.3 비지도학습에서의 베이스라인

비지도학습은 대개 정답 레이블이 없으므로 지도학습처럼 정확도를 기준선으로 삼기 어렵다. 군집분석의 비교 기준은 다음처럼 설정할 수 있다.

- **단순한 초기 기준:** 표준화된 특성에 K-Means를 적용한다.
- **군집 수 비교:** 동일한 전처리에서 서로 다른 $K$를 비교한다.
- **방법 비교:** 같은 입력 특성·평가 기준으로 K-Means와 계층적 군집화 등을 비교한다.
- **해석 가능성:** 군집 간 구매 특성 차이가 실제로 설명 가능하고, 표본 수가 충분한지 살펴본다.
- **안정성:** 난수 시드나 표본을 변경해도 유사한 패턴이 나타나는지 확인한다.

**중요:** K-Means 자체가 군집화 문제의 ‘첫 번째 기준 모델’이 될 수 있지만, 무작위 레이블과 무조건 비교한다고 해서 의미 있는 성능 검증이 완성되지는 않는다. 군집화는 지표뿐 아니라 연구 목적에 대한 타당성이 중요하다.

### 3.4 신경망 베이스라인의 기본 구조

딥러닝 문제에서도 처음부터 대규모 모델을 사용하기보다, 입력층·은닉층·출력층으로 이루어진 간단한 **다층 퍼셉트론(MLP)** 을 기준 모델로 사용할 수 있다.

- **뉴런(Neuron):** 입력에 가중치를 곱해 더한 뒤 활성화 함수를 적용하는 계산 단위다.
- **가중치(Weight), 편향(Bias):** 학습 과정에서 조정되는 파라미터다.
- **활성화 함수(Activation):** 비선형 관계를 표현하도록 도와준다. 대표적으로 ReLU, Sigmoid 등이 있다.
- **손실함수(Loss Function):** 모델의 예측과 학습 목표 사이의 차이를 수치화한다.
- **역전파(Backpropagation):** 연쇄법칙을 이용해 손실의 기울기를 각 파라미터로 전파한다.
- **최적화기(Optimizer):** 기울기를 사용해 파라미터를 갱신한다. SGD, Adam 등이 대표적이다.
- **에포크(Epoch):** 전체 훈련 데이터를 한 번 학습에 사용하는 단위다.
- **배치(Batch):** 파라미터 갱신을 위해 한 번에 사용하는 샘플 묶음이다.

뉴런의 전형적인 계산은 다음과 같이 나타낸다.

$$
z=\sum_{j=1}^{d}w_jx_j+b,\qquad a=\phi(z)
$$

손실함수를 $L$, 파라미터를 $\theta$, 학습률을 $\eta$라고 하면 기본적인 경사하강법은

$$
\theta_{t+1}=\theta_t-\eta\nabla_{\theta}L(\theta_t)
$$

로 표현한다. 복잡한 모델보다 이 간단한 모델이 실제로 성능을 높이는지 확인하는 것이 베이스라인 실험의 핵심이다.

### 3.5 문제에 맞는 성능 평가 지표

| 학습 문제 | 대표 평가 지표 | 해석 시 핵심 |
| --- | --- | --- |
| 분류 | Accuracy, Precision, Recall, F1, ROC-AUC | 불균형 데이터에서 정확도만으로 판단하지 않는다. |
| 회귀 | MAE, MSE, RMSE, R² | 오차의 단위와 극단값에 대한 민감도를 확인한다. |
| 군집화 | Silhouette, Davies–Bouldin, Calinski–Harabasz | 군집의 기하학적 분리와 실제 분석 목적을 함께 검토한다. |

- **정밀도(Precision)** = TP / (TP + FP): 양성이라고 예측한 사례 중 실제 양성의 비율.
- **재현율(Recall)** = TP / (TP + FN): 실제 양성 중 모델이 찾아낸 비율.
- **F1** = 2 × Precision × Recall / (Precision + Recall): 정밀도와 재현율의 조화평균.
- **MAE** = 실제값과 예측값의 절댓값 차이의 평균.
- **MSE** = 실제값과 예측값의 차이를 제곱한 값의 평균.

분모가 0이 되는 특수한 경우에는 지표의 정의·라이브러리 처리 규칙을 확인해야 한다.

## 4. 데이터 준비와 실험 설계

### 4.1 전처리의 주요 단계

1. **데이터 이해:** 행은 관측 대상, 열은 변수라는 구조를 확인하고 각 변수의 의미·단위·분포를 점검한다.
2. **결측값 처리:** 제거 또는 적절한 대치 방법을 선택한다. 결측 자체가 정보인지도 검토한다.
3. **중복·이상치 확인:** 중복 거래와 중복 고객을 구분하고, 실제 관측값인 극단치를 무조건 삭제하지 않는다.
4. **변수 선택:** 연구 질문과 관계없는 식별자, 사후에만 알 수 있는 변수, 중복된 의미의 변수를 점검한다.
5. **인코딩:** 범주형 변수를 알고리즘이 처리할 수 있도록 표현한다.
6. **스케일링:** 거리나 최적화에 영향을 주는 변수의 척도를 조정한다.

### 4.2 수치형·범주형 변수

- **수치형:** 나이, 구매금액, 이전 구매횟수 등.
- **명목형 범주:** 성별, 배송 방식, 결제 방식, 지역 등. 항목 사이에 본래의 크기 순서는 없다.
- **순서형 범주:** 만족도 등급 등. 순서는 있지만 등급 간 간격이 같다는 보장은 없다.

명목형 범주에 단순히 0·1·2·3을 붙여 K-Means에 넣으면 **존재하지 않는 순서와 거리를 알고리즘에 강요**할 수 있다. One-Hot Encoding이 일반적인 대안이지만, 범주가 많거나 변수 구성에 따라 거리 해석이 왜곡될 수 있다. 혼합형 데이터에는 K-Prototypes나 Gower 거리와 호환되는 군집화 방법 등을 대안으로 검토할 수 있다.

### 4.3 표준화(Standardization)

각 변수의 평균을 0, 표준편차를 1로 변환하는 대표적 방법이다.

$$
z_i = \frac{x_i - \mu}{\sigma}
$$

- $x_i$: 원래 관측값
- $\mu$: 해당 변수의 평균
- $\sigma$: 해당 변수의 표준편차

구매금액이 수십~수백이고 이전 구매횟수가 한 자릿수~수십이라면, 원자료에서 유클리드 거리를 계산할 때 구매금액의 척도가 결과를 지배할 수 있다. **표준화는 변수의 영향력을 조정하는 방법이지만 모든 편향을 해결해 주지는 않는다.** 이상치에 민감한 경우 RobustScaler 같은 대안을 고려한다.

### 4.4 훈련·검증·테스트 분리

**지도학습**에서는 모델을 학습하는 훈련 세트, 모델·하이퍼파라미터를 선택하는 검증 세트, 최종 성능을 확인하는 테스트 세트를 구분한다. 표본이 적다면 교차검증을 활용할 수 있다.

- 훈련 세트(Train): 모델 파라미터 학습.
- 검증 세트(Validation): 모델 구조·하이퍼파라미터 선택.
- 테스트 세트(Test): 선택 과정이 끝난 모델에 대한 독립적인 최종 평가.

전처리에서 평균·표준편차·결측값 대치 규칙 등 데이터로부터 추정해야 하는 값은 **훈련 데이터로만 학습(fit)** 하고, 검증·테스트에는 그 변환을 적용(transform)해야 한다. 전체 데이터를 미리 표준화한 후 분리하면 데이터 누수(data leakage)가 발생할 수 있다.

**비지도 군집화**에서는 탐색적 분석을 위해 전체 표본에 군집화를 적용하기도 한다. 따라서 지도학습과 똑같은 분리 규칙을 무조건 적용하는 것은 아니다. 다만 새로운 고객에 대한 일반화·안정성을 주장하려면 별도의 평가 설계(표본 분할, 재표본화, 재현성 검증 등)가 필요하다.

### 4.5 과적합(Overfitting)과 과소적합(Underfitting)

- **과적합:** 훈련 데이터의 우연한 패턴까지 지나치게 학습하여 새로운 데이터에서 성능이 떨어지는 현상이다.
- **과소적합:** 모델이 지나치게 단순하거나 학습이 부족하여 훈련 데이터의 중요한 구조조차 설명하지 못하는 상태다.
- **규제(Regularization):** 모델의 복잡도나 파라미터에 제약을 주어 과적합을 완화하는 방법이다.
- **조기 종료(Early Stopping):** 검증 성능을 관찰하며 불필요한 추가 학습을 멈추는 방법이다.

모델의 성능을 개선할 때는 학습 점수만 높이는 대신 **훈련 성능과 검증 성능의 차이**를 함께 살펴봐야 한다. 이는 특히 지도학습의 베이스라인 모델을 확장할 때 중요하다.

## 5. K-Means 군집화

### 5.1 기본 개념

K-Means는 **데이터를 미리 지정한 $K$개의 군집으로 나누고, 각 군집 내부의 제곱거리 합을 작게 만드는** 군집화 알고리즘이다.

- $K$: 군집의 개수. 알고리즘을 실행하기 전에 정한다.
- 중심점(Centroid): 한 군집에 속한 관측치들의 특성별 평균 벡터.
- 할당(Assignment): 각 관측치를 가장 가까운 중심점의 군집으로 배정하는 단계.
- 갱신(Update): 군집에 속한 관측치의 평균으로 중심점을 다시 계산하는 단계.

중심점은 반드시 실제 데이터 관측치 중 하나일 필요는 없다.

### 5.2 유클리드 거리(Euclidean Distance)

두 점 $x=(x_1, x_2, \ldots, x_d)$, $y=(y_1, y_2, \ldots, y_d)$ 사이의 거리는

$$
d(x,y)=\sqrt{\sum_{j=1}^{d}(x_j-y_j)^2}
$$

이다. K-Means는 가장 가까운 중심점을 선택할 때 유클리드 거리를 이용하며, 목적함수에는 거리의 **제곱**이 들어간다.

2차원에서 $A=(1,2)$, $B=(4,6)$이면

$$
d(A,B)=\sqrt{(4-1)^2+(6-2)^2}=5
$$

이다.

### 5.3 목적함수: WCSS / Inertia

$$
J = \sum_{k=1}^{K}\sum_{x_i \in C_k}\|x_i-\mu_k\|_2^2
$$

- $C_k$: $k$번째 군집에 속한 데이터의 집합
- $\mu_k$: $k$번째 군집의 중심점
- $\|x_i-\mu_k\|_2^2$: 한 데이터와 중심점 사이 거리의 제곱
- $J$: 전체 군집 안에서 발생하는 제곱거리의 합

이 값은 **Within-Cluster Sum of Squares(WCSS)** 또는 **Inertia**라고 부른다. 같은 데이터·특성 공간에서 다른 조건을 고정하고 비교한다면 작을수록 응집도가 높다는 뜻이다. 그러나 작다고 해서 무조건 좋은 군집이라고 단정할 수는 없다.

### 5.4 동작 과정

1. 원하는 군집 수 $K$를 지정한다.
2. $K$개의 초기 중심점을 정한다. 보통 `k-means++` 방식이 사용된다.
3. 모든 관측치를 가장 가까운 중심점으로 할당한다.
4. 각 군집에 포함된 관측치의 평균을 계산해 중심점을 갱신한다.
5. 중심점 변화가 충분히 작아지거나 반복 한도에 도달할 때까지 3~4단계를 반복한다.

이 과정을 **Lloyd 알고리즘**이라고 부르는 경우가 많다. 각 반복은 목적함수를 증가시키지 않는 방향으로 진행하지만, 전역 최적해를 항상 찾는 것은 아니다. 초기 중심점에 따라 서로 다른 지역 최적해(local optimum)에 수렴할 수 있다.

### 5.5 초기화, 반복, 재현성

- **k-means++:** 서로 구분되는 초기 중심점을 효과적으로 선택하도록 설계된 초기화 기법.
- **n_init:** 서로 다른 초기화로 반복 실행할 횟수. 가장 낮은 Inertia를 보인 결과를 선택한다.
- **max_iter:** 각 실행에서 허용하는 최대 반복 횟수.
- **tol:** 중심점 변화에 기반한 수렴 허용 오차.
- **random_state:** 난수 사용 과정을 고정하여 같은 설정에서 결과를 재현하도록 돕는다.

실험 보고서에는 $K$, 특성 목록, 전처리 방법, 난수 시드, 초기화 설정을 기록한다.

### 5.6 K-Means의 장점과 한계

**장점**

- 알고리즘이 비교적 단순하며 빠르다.
- 결과를 군집 중심과 군집별 특성 평균으로 설명할 수 있다.
- 기본 군집화 모델로 활용하기 좋다.

**한계**

- $K$를 사전에 정해야 한다.
- 초기화와 이상치에 영향을 받을 수 있다.
- 유클리드 거리와 평균 중심에 적합한 형태를 가정해, 길쭉하거나 복잡한 밀도 구조를 제대로 분리하지 못할 수 있다.
- 스케일과 변수 선택에 민감하다.
- 순수 범주형 또는 혼합형 데이터에 그대로 적용하면 거리의 의미가 부적절할 수 있다.
- 관측된 군집이 실재하는 고객 유형이라는 증거는 아니다.

## 6. 군집 수 K 선택하기

### 6.1 Elbow Method(엘보 방법)

서로 다른 $K$에 대해 K-Means를 실행하고 $K$와 Inertia를 그래프로 그린다. $K$가 커질수록 Inertia는 일반적으로 감소하므로, 감소 폭이 눈에 띄게 둔화하는 **팔꿈치 지점**을 후보로 삼는다.

**주의 사항**

- Inertia는 $K$를 크게 할수록 대체로 줄어든다. 따라서 'Inertia가 가장 작은 K'를 그대로 선택하는 것은 잘못된 접근이다.
- 팔꿈치가 분명하지 않은 데이터도 있다.
- Elbow Method는 최적의 $K$를 수학적으로 보장하지 않는 휴리스틱이다.

### 6.2 Silhouette Score(실루엣 계수)

관측치 $i$에 대해 다음을 정의한다.

- $a(i)$: 자신이 속한 군집의 다른 관측치들과의 평균 거리.
- $b(i)$: 다른 각 군집까지의 평균 거리를 구했을 때, 그중 가장 작은 값.

실루엣 계수는

$$
s(i)=\frac{b(i)-a(i)}{\max(a(i),b(i))}
$$

이다. 전체 Silhouette Score는 개별 관측치의 계수를 평균한 값이다.

| 값 | 일반적인 해석 |
| --- | --- |
| 1에 가까움 | 자신의 군집과 가깝고 다른 군집과 잘 구분됨 |
| 0에 가까움 | 두 군집의 경계 부근에 놓임 |
| -1에 가까움 | 다른 군집과 더 가까워 잘못 배정되었을 가능성 |

실루엣 계수의 값 범위는 **-1에서 1**이다. 일반적인 구현에서 서로 다른 군집이 최소 2개, 관측치 수보다 적게 있어야 계산 가능하다. 단일 관측치로 이루어진 군집의 실루엣 계수는 관례상 0으로 취급된다.

**핵심:** 실루엣 점수가 가장 높은 $K$가 반드시 고객 세분화의 실무 목적에 가장 적합한 $K$는 아니다. 군집 크기의 균형, 안정성, 해석 가능성, 실제 활용 가능성을 함께 살펴봐야 한다.

### 6.3 그 밖의 지표

- **Davies–Bouldin Index:** 군집 내부 산포와 군집 간 분리를 함께 측정한다. 일반적으로 낮을수록 좋다.
- **Calinski–Harabasz Index:** 군집 간 분산과 군집 내 분산의 비율에 기반한다. 일반적으로 높을수록 좋다.
- **외부 지표:** 실제 정답 군집 레이블이 별도로 있을 때 ARI·NMI 등을 활용할 수 있다. 고객 구매 데이터에는 이러한 정답이 없는 경우가 많다.

지표는 모두 군집의 특정한 기하학적 성질을 반영하므로, 하나만으로 분석의 가치를 확정해서는 안 된다.

## 7. PCA와 군집 시각화

### 7.1 PCA(Principal Component Analysis)

PCA는 여러 변수의 선형 결합으로 이루어진 새로운 축인 **주성분(Principal Component)** 을 찾는 차원 축소 방법이다. 첫 번째 주성분은 데이터의 분산을 가장 크게 설명하는 방향이고, 다음 주성분은 앞선 주성분과 직교하면서 남은 분산을 크게 설명하는 방향이다.

### 7.2 군집화에서 PCA를 사용하는 두 가지 방식

1. **시각화 목적:** 원래 특성 공간에서 K-Means를 학습하고, 결과를 PCA의 2개 주성분 위에 표현한다.
2. **학습 전 차원 축소:** 표준화된 데이터를 PCA로 차원 축소한 뒤, 축소된 공간에서 K-Means를 학습한다.

두 방식은 **서로 다른 실험**이다. PCA로 2차원에 투영한 산점도에서 군집이 겹쳐 보이더라도 원래 고차원 공간에서 분리가 잘 되어 있을 수 있고, 반대로 2차원 그림이 선명해 보여도 실제 군집의 의미가 보장되지는 않는다.

### 7.3 설명분산비(Explained Variance Ratio)

각 주성분이 전체 분산의 어느 정도를 설명하는지 나타내는 값이다. 예를 들어 PC1이 35%, PC2가 20%를 설명한다면 2차원 시각화로 전체 분산의 55%를 설명한다는 뜻이며, 남은 45%는 그 그림에 직접 반영되지 않는다.

## 8. COW 팀 실습 적용: 쇼핑 데이터 고객 세분화

### 8.1 분석 질문부터 정하기

단순히 군집 번호만 나열하는 대신 구체적인 질문을 설정한다.

- 구매금액과 이전 구매횟수가 비슷한 고객이 같은 군집으로 묶이는가?
- 높은 구매금액을 보이는 군집과 높은 재구매 경험을 보이는 군집은 동일한가?
- 만들어진 군집은 배송 방식·할인 이용 등과 어떤 관계를 보이는가?
- 군집별 구매금액의 평균뿐 아니라 분포와 표본 수는 어떻게 다른가?

**데이터 성격 주의:** 사용 중인 Shopping Behavior 데이터의 실제 수집·생성 경위와 표본 대표성은 별도 확인이 필요하다. 인위적으로 구성된 데이터라면 분석 결과를 실존 소비자 집단의 일반적 특성으로 확대 해석할 수 없다.

### 8.2 변수 선택 예시

다음은 실제 파일에 해당 열이 있는지를 확인한 뒤 적용할 수 있는 예시다.

| 변수 예시 | 유형 | 활용 시 검토 사항 |
| --- | --- | --- |
| Age | 수치형 | 연령 분포와 이상치 확인 |
| Purchase Amount (USD) | 수치형 | 척도 차이 및 극단값 확인 |
| Previous Purchases | 수치형 | 과거 구매횟수라는 의미 및 분포 확인 |
| Frequency of Purchases | 범주형 또는 순서형 | 원본 값의 의미 확인 후 인코딩 방법 선택 |
| Shipping Type | 명목형 범주 | 원-핫 인코딩 가능 여부, 군집화 목적 검토 |
| Subscription Status | 이진 범주 | 행동 특성으로 사용할지 결과 해석에만 쓸지 결정 |
| Customer ID | 식별자 | 일반적으로 모델 입력에서 제외 |

**추천하는 비교 실험**

- **실험 A — 최소 기준선:** `Age`, `Purchase Amount (USD)`, `Previous Purchases`처럼 의미가 명확한 수치 변수 위주로 선택 → 표준화 → K-Means.
- **실험 B — 변수 확장:** 의미를 검증한 구매 빈도 등 추가 → 적합한 인코딩·스케일링 → K-Means.
- **실험 C — 방법 비교:** 동일한 특성으로 다른 군집화 알고리즘과 결과 비교.

A와 B의 결과가 다르면 단순히 더 높은 실루엣 점수만 볼 것이 아니라 **무슨 변수를 추가했기 때문에 고객 구분 기준이 달라졌는지** 설명해야 한다.

### 8.3 권장 분석 절차

1. 데이터 사전과 열의 의미를 점검한다.
2. 결측값, 중복값, 분포, 이상치 및 범주별 빈도를 확인한다.
3. 고객 세분화의 목적에 따라 입력 변수를 결정한다.
4. 변수의 자료형에 맞는 인코딩·스케일링을 수행한다.
5. K-Means로 여러 $K$를 시험하고 Inertia·Silhouette Score를 기록한다.
6. 점수와 군집 크기, 초기화에 따른 안정성을 함께 비교해 후보 $K$를 선택한다.
7. 군집별 원래 단위의 통계량(평균·중앙값·분포·빈도)을 비교한다.
8. PCA 2차원 시각화를 보조 자료로 제시하고 설명분산비를 표기한다.
9. 군집에 이름을 붙일 경우, 이름의 근거가 되는 실제 통계적 차이를 함께 제시한다.
10. 데이터 생성 경위·대표성·변수 구성·군집 안정성 등 한계를 정리한다.

### 8.4 해석 예시: 무엇이 근거인가?

**부적절한 해석:** "군집 2는 충성 고객이고, 군집 3은 이탈 위험 고객이다."

이 문장은 실제 충성도나 이탈 레이블을 측정하지 않았다면 근거가 없다.

**더 적절한 해석:** "군집 2는 다른 군집과 비교했을 때 이전 구매횟수와 구매금액의 중앙값이 높게 관측되었다. 따라서 이 집단을 '과거 구매 경험이 많은 고객군'으로 기술할 수 있다. 다만 실제 충성도와 미래 재구매 여부는 이 데이터만으로 판단할 수 없다."

### 8.5 발표 결과물의 최소 구성

- 연구 질문과 데이터 설명
- 입력 변수와 전처리 선택 근거
- 군집 수 $K$를 결정한 과정
- Elbow 그래프와 Silhouette Score 비교
- 군집별 인원 수와 주요 특성 요약
- PCA 산점도 및 설명분산비
- 발견한 패턴, 해석의 근거, 분석의 한계

## 9. 자주 혼동하는 개념

| 개념 A | 개념 B | 핵심 차이 |
| --- | --- | --- |
| 분류(Classification) | 군집화(Clustering) | 분류는 보통 정답 범주를 학습하고, 군집화는 유사성으로 구조를 찾는다. |
| 파라미터(Parameter) | 하이퍼파라미터(Hyperparameter) | 파라미터는 학습으로 정해지고, 하이퍼파라미터는 보통 학습 전에 설정한다. K-Means의 중심점은 파라미터, K는 하이퍼파라미터다. |
| 표준화(Standardization) | 정규화(Normalization) | 표준화는 보통 평균·표준편차 기반 변환이다. 정규화는 문맥에 따라 0~1 범위 변환이나 벡터 길이 1 변환 등을 뜻할 수 있다. |
| Inertia | Silhouette Score | Inertia는 군집 내부 제곱거리 합, Silhouette는 군집 내부 응집과 다른 군집과의 분리를 함께 본다. |
| PCA | K-Means | PCA는 차원 축소, K-Means는 군집화다. 서로 대체 관계가 아니다. |
| 군집 레이블 | 정답 레이블 | 군집 레이블은 알고리즘이 부여한 번호이며 실제 정답 또는 인과적 유형을 뜻하지 않는다. |
| 학습 데이터 성능 | 일반화 성능 | 학습 데이터에서 잘 맞는 것과 새로운 데이터에서도 성능이 유지되는 것은 다르다. |
| 상관관계 | 인과관계 | 두 변수가 함께 나타나더라도 한쪽이 다른 쪽의 원인이라는 뜻은 아니다. |

## 10. 핵심 확인 문제 및 모범 답안

**Q1. 딥러닝과 머신러닝의 관계는?**  
A. 딥러닝은 다층 신경망을 이용하는 머신러닝의 하위 분야다.

**Q2. 베이스라인 없이 복잡한 모델부터 만들면 무엇이 문제인가?**  
A. 성능과 비용이 실제로 개선되었는지 비교할 기준이 없다.

**Q3. 모든 데이터를 평균으로만 예측하는 모델이 회귀의 기준선이 되는 이유는?**  
A. 입력 특성을 활용하지 않는 단순 예측보다 새로운 모델이 개선되는지 확인할 수 있기 때문이다.

**Q4. 쇼핑 데이터에서 K-Means는 지도학습인가?**  
A. 정답 고객 유형 없이 유사성으로 묶으므로 비지도학습이다.

**Q5. K-Means가 줄이려는 값은?**  
A. 각 관측치와 자신이 속한 군집 중심 사이의 제곱거리 합(WCSS, Inertia)이다.

**Q6. 군집 수 K를 늘리면 Inertia가 대체로 줄어드는 이유는?**  
A. 군집 중심이 많아지면 같은 데이터를 더 세밀하게 나누어 각 점과 가장 가까운 중심 사이 거리를 줄일 수 있기 때문이다.

**Q7. 실루엣 계수가 음수라면?**  
A. 해당 관측치는 자신의 군집보다 다른 군집과 평균적으로 더 가까울 가능성이 있다.

**Q8. 구매금액과 구매횟수를 표준화하는 이유는?**  
A. 변수마다 단위와 수치 범위가 달라 특정 변수가 유클리드 거리를 지배하는 현상을 줄이기 위해서다.

**Q9. 고객 번호를 K-Means 입력에 넣는 것이 보통 부적절한 이유는?**  
A. 고객 번호는 통상 식별자이지 고객 간 유의미한 거리나 구매행동을 나타내지 않기 때문이다.

**Q10. PCA에서 군집이 분리되어 보이면 실제 고객 유형을 발견했다고 단정할 수 있는가?**  
A. 없다. 2차원 투영의 특성, 군집 안정성, 입력 변수의 의미와 실제 데이터 대표성을 검토해야 한다.

**Q11. 테스트 데이터를 미리 표준화에 포함시키면?**  
A. 테스트 데이터의 통계량이 학습·선택 과정에 들어가 데이터 누수가 발생할 수 있다.

**Q12. K-Means 군집 번호 0, 1, 2에는 크기 순서가 있는가?**  
A. 없다. 군집 번호는 임의의 레이블이다.

## 11. 최종 요약

- **머신러닝**은 데이터에서 패턴을 학습하고, **딥러닝**은 그중 다층 신경망을 활용하는 방법이다.
- **지도학습**은 정답 레이블이 있고, **비지도학습**은 정답 없이 데이터 구조를 탐색한다.
- **베이스라인**은 복잡한 방법의 성능과 비용이 실제로 개선되는지 판단하는 출발점이다.
- **K-Means**는 지정한 $K$개 군집에서 중심점과 관측치 사이 제곱거리 합을 최소화한다.
- **Elbow Method**는 Inertia 감소 곡선의 완만해지는 지점을, **Silhouette Score**는 군집의 응집과 분리를 평가한다.
- **PCA**는 고차원 데이터를 저차원으로 표현하지만, 시각화 결과 자체가 군집의 실재성을 보증하지는 않는다.
- 우리 팀의 실습에서는 **변수 선택의 근거 → 전처리 → K 선택 → 군집별 통계 비교 → 해석의 한계**가 가장 중요하다.
