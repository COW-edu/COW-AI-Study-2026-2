# 정형·반정형·비정형 데이터 이론 정리

데이터는 구조와 표현 방식에 따라 정형 데이터, 반정형 데이터, 비정형 데이터로 나눌 수 있습니다. 각 데이터의 특징과 저장·활용 방법을 이해하면 데이터베이스를 설계하고 분석 방법을 선택하는 데 도움이 됩니다.

## 1. 데이터란?

데이터(Data)는 대상이나 현상을 관찰·측정해 얻은 사실 또는 값입니다. 컴퓨터는 데이터를 저장하고 처리해 정보와 지식을 만들어 냅니다. 데이터의 구조를 파악하는 일은 데이터베이스 설계, 데이터 분석, 머신러닝 및 인공지능 개발의 기초입니다.

## 2. 정형 데이터 (Structured Data)

### 정의

정형 데이터는 미리 정해진 구조와 형식에 맞춰 저장되는 데이터입니다. 일반적으로 행(Row)과 열(Column)로 된 표로 나타내며, 각 열의 이름과 자료형, 의미가 명확합니다. 관계형 데이터베이스(RDBMS)의 테이블이 대표적인 예입니다.

### 특징

- 구조와 항목의 의미가 명확합니다.
- 정해진 스키마와 자료형을 따릅니다.
- SQL로 조건 검색, 집계, 정렬을 하기 쉽습니다.
- 데이터의 일관성과 무결성을 관리하기 쉽습니다.
- 구조가 고정되어 있어 새로운 형태의 정보를 반영하려면 스키마 변경이 필요할 수 있습니다.

### 예시

| 학번 | 이름 | 학과 | 학년 | 평균 학점 |
|---|---|---|---:|---:|
| 2026001 | 김민수 | 컴퓨터공학과 | 2 | 3.8 |
| 2026002 | 이지훈 | 인공지능학과 | 3 | 4.1 |
| 2026003 | 박서연 | 소프트웨어학과 | 1 | 3.5 |

각 열이 의미하는 바와 값의 형식이 정해져 있어 조건에 따라 쉽게 조회할 수 있습니다.

```sql
SELECT 이름, 학과, 평균_학점
FROM student
WHERE 평균_학점 >= 4.0;
```

### 대표 사례

학생·고객·상품 정보, 주문 및 판매 기록, 은행 거래 내역, 재고 현황, 날짜별 센서 측정값 등이 있습니다.

## 3. 반정형 데이터 (Semi-structured Data)

### 정의

반정형 데이터는 관계형 테이블처럼 고정된 행과 열 구조를 따르지는 않지만, 태그(Tag), 키(Key), 값(Value), 계층 구조 또는 메타데이터를 이용해 데이터의 구조와 의미를 일부 표현하는 데이터입니다.

### 특징

- 모든 레코드가 똑같은 항목을 가지지 않아도 됩니다.
- 데이터 안에 항목의 이름이나 관계가 함께 표현됩니다.
- 구조가 유연해 항목을 추가하거나 변경하기 쉽습니다.
- 분석 전에 형식을 확인하고 필요한 형태로 변환하는 과정이 필요할 수 있습니다.

### 예시: JSON

```json
{
  "student_id": 2026001,
  "name": "김민수",
  "department": "컴퓨터공학과",
  "courses": [
    {"name": "데이터베이스", "grade": "A"},
    {"name": "통계학", "grade": "B+"}
  ]
}
```

키 이름이 데이터 항목의 의미를 알려 주고, `courses`처럼 배열 안에 여러 값을 담을 수도 있습니다.

### 대표 형식과 사례

- JSON: 웹 API 응답, 설정 파일
- XML: 문서 교환, 시스템 간 데이터 전달
- YAML: 애플리케이션 설정 파일
- 로그: 시간, 수준, 메시지 등 항목을 포함한 이벤트 기록

## 4. 비정형 데이터 (Unstructured Data)

### 정의

비정형 데이터는 표와 같이 미리 고정된 데이터 모델이나 스키마로 표현하기 어려운 데이터입니다. 내용과 형식이 다양해 단순한 행·열 기반 질의만으로 의미를 파악하기 어렵습니다.

### 특징

- 고정된 항목과 자료형이 데이터 전체에 일관되게 적용되지 않습니다.
- 텍스트, 이미지, 음성, 영상처럼 표현 방식이 다양합니다.
- 의미를 추출하려면 검색, 자연어 처리, 이미지·음성 인식 등 별도 처리가 필요할 수 있습니다.
- 파일 자체와 함께 작성자, 생성 시각, 위치 같은 메타데이터를 관리하기도 합니다.

### 종류와 사례

| 종류 | 예시 |
|---|---|
| 텍스트 | 뉴스 기사, 이메일, SNS 게시글, 고객 리뷰, 문서 |
| 이미지 | 사진, 의료 영상, 위성 사진, 상품 이미지 |
| 음성 | 통화 녹음, 음성 메모, 음악, 음성 명령 |
| 영상 | CCTV, 강의 영상, 영화, 스포츠 경기 영상 |

## 5. 세 가지 데이터 비교

| 구분 | 정형 데이터 | 반정형 데이터 | 비정형 데이터 |
|---|---|---|---|
| 구조 | 고정된 행·열과 스키마 | 태그·키·계층 등으로 일부 표현 | 고정된 표 구조가 없음 |
| 형식 예 | 관계형 데이터베이스 테이블 | JSON, XML, YAML, 로그 | 문서, 이미지, 음성, 영상 |
| 스키마 | 사전에 엄격히 정의 | 유연하거나 레코드마다 다를 수 있음 | 데이터 내용과 별도로 관리하는 경우가 많음 |
| 처리 예 | SQL 조회와 집계 | 파싱 후 필요한 필드 추출 | 검색, 자연어 처리, 이미지·음성 인식 |
| 장점 | 조회와 분석이 쉽고 일관성 관리에 유리 | 구조 변경에 유연함 | 다양한 정보를 원래 형태에 가깝게 보존 |
| 고려 사항 | 스키마 변경이 부담이 될 수 있음 | 형식 차이와 누락 항목을 처리해야 함 | 저장·검색·분석에 더 복잡한 처리가 필요할 수 있음 |

> 실제 데이터는 항상 한 종류로만 나뉘지 않습니다. 예를 들어 고객 리뷰의 본문은 비정형 텍스트지만, 작성자 ID와 작성 날짜는 정형 데이터이고, 리뷰와 함께 저장된 별점은 정형 데이터일 수 있습니다.

## 6. 데이터 활용 사례

온라인 쇼핑몰의 주문 정보를 예로 들면 다음과 같이 여러 유형의 데이터가 함께 사용됩니다.

- **정형 데이터:** 주문 번호, 고객 ID, 상품 ID, 수량, 결제 금액
- **반정형 데이터:** 외부 결제 API에서 받은 JSON 응답
- **비정형 데이터:** 상품 사진, 고객 문의 메시지, 상담 녹음

서비스에서는 이 데이터를 목적에 맞게 저장하고 연결합니다. 주문 통계에는 정형 데이터가, API 통신에는 반정형 데이터가, 문의 내용의 분류나 사진 검색에는 비정형 데이터 분석이 활용될 수 있습니다.

## 7. 핵심 정리

- **정형 데이터**는 미리 정해진 표 구조에 맞춰 저장하며, 조회와 집계가 쉽습니다.
- **반정형 데이터**는 키·태그·계층 구조로 의미를 표현하고, 고정된 표보다 유연합니다.
- **비정형 데이터**는 고정된 표 구조가 없으며 텍스트, 이미지, 음성, 영상 등이 포함됩니다.
- 데이터의 유형에 따라 적절한 저장 방식과 처리 방법을 선택해야 합니다.
- 하나의 서비스에서도 세 가지 데이터 유형이 함께 존재할 수 있습니다.

## 참고 용어

- **스키마(Schema):** 데이터의 구조, 항목, 자료형 및 제약 조건을 정의한 설계
- **RDBMS:** 데이터를 관계형 테이블로 저장하고 SQL 등으로 관리하는 데이터베이스 관리 시스템
- **메타데이터(Metadata):** 데이터의 작성자, 생성 시각, 형식 등 데이터를 설명하는 정보
